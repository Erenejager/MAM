# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

MAM is a single-user Media Asset Management application. Users upload video files; the system extracts metadata via ffprobe, generates thumbnails via ffmpeg, transcribes via Groq API (Whisper large-v3), and indexes to OpenSearch for full-text search. Deployment target: Hetzner server accessed via Tailscale.

## Commands

All commands are run from within their respective subdirectory (`backend/` or `frontend/`).

### Backend (`cd backend`)

```bash
npm run dev          # tsx watch — hot-reloads on file change
npm run build        # tsc — compiles to dist/
npm run db:generate  # drizzle-kit generate — create new migration from schema changes
npm run db:migrate   # apply pending migrations
npm test             # vitest
npx vitest run src/__tests__/ingest.test.ts   # run a single test file
```

### Frontend (`cd frontend`)

```bash
npm run dev     # Vite dev server (http://localhost:5173)
npm run build   # tsc + vite build
```

### Environment (backend)

Copy `.env.example` to `.env`. Required vars that block startup: `GROQ_API_KEY`, `STORAGE_ROOT` (must be an existing directory). Optional: `OPENSEARCH_URL` (defaults to `http://localhost:9200` — failure is a warning, not fatal), `DATABASE_PATH` (defaults to `~/.mam/mam.db`), `PORT` (defaults to `3001`).

System `ffmpeg` must be installed (`apt-get install ffmpeg`). Do NOT use `@ffmpeg-installer/ffmpeg`.

## Architecture

```
frontend/   React 18 + Vite + Tailwind CSS 3 + TypeScript
backend/    Fastify 4 + better-sqlite3/Drizzle + p-queue + TypeScript (ESM)
```

**Boot sequence** (`backend/src/index.ts`): dotenv → `validateEnv()` → CORS → register routes → `initOpenSearch()` → listen. The DB connection is a side-effect of importing `./db/index.js`.

**Ingest pipeline** (`backend/src/routes/assets.ts` → `lib/queue.ts`): `POST /api/assets` streams the file to `STORAGE_ROOT/{uuid}/original.{ext}` while computing SHA-256 via `saveAndHash()`, rejects duplicates with 409, inserts an `assets` row with `status='ingesting'`, and enqueues a pipeline job — then immediately returns 202. The pipeline runs as `pipelineQueue` (concurrency 1 to prevent SQLite BUSY errors) and will execute stages: ffprobe → thumbnail → Groq transcription → OpenSearch indexing. Each stage has its own `*_status` column so partial failures don't block the rest.

**Storage layout**:
```
{STORAGE_ROOT}/
  {asset-uuid}/
    original.{ext}     ← never mutated after ingest
    thumbnail.jpg      ← generated by ffmpeg
    transcript.json    ← Groq API output (segments with timestamps)
```

**Database** (`backend/src/db/schema.ts`): Three tables — `assets` (primary metadata + per-stage status columns), `custom_fields` (user-defined field definitions), `asset_custom_values` (EAV values). Tags are stored as a JSON array string in `assets.tags` — use SQLite's `json_each()` for tag filtering. SQLite is the source of truth; OpenSearch is a derived, rebuildable index. Never query OpenSearch for metadata display — only for search queries.

**OpenSearch** (`backend/src/bootstrap/opensearch.ts`): Index name `mam-assets`. Connection failure on startup is a warning, not fatal — the app runs without search. `@opensearch-project/opensearch` client major version must match the running OpenSearch instance.

**Video serving**: Uploaded files are served via `@fastify/static` at `/storage/{asset-uuid}/original.{ext}`. Range requests are handled automatically, enabling `<video>` seek in the browser.

**Tests** (`backend/src/__tests__/`): All currently stubs (`it.todo`). Tests go in `src/__tests__/*.test.ts` per `vitest.config.ts`.

## Design System

Defined in `design-system/mam/MASTER.md`. Cinema Dark aesthetic — desktop only (1024px minimum, no mobile breakpoints).

| Role | Hex | Tailwind equivalent |
|------|-----|---------------------|
| Background | `#0F0F23` | custom (`bg-background`) |
| Panel/Surface | `#1E1B4B` | custom (`bg-panel`) |
| CTA/Accent | `#E11D48` | custom (`bg-cta`) |
| Text | `#F8FAFC` | `text-slate-50` |
| Text Muted | `#94A3B8` | `text-slate-400` |
| Border | `#2D2A5E` | custom (`border-border`) |

Fonts: **Fira Code** (headings/monospace), **Fira Sans** (body). Loaded via Google Fonts. Font weights: 400 and 600 only (500 is not used).

**Tailwind 3 is locked** — do not upgrade to Tailwind 4. shadcn/ui and MCP Magic 21st.dev components are incompatible with Tailwind 4's CSS-based config as of March 2026.

Video player uses native `<video>` with custom controls (not Video.js or react-player). Transcript sync uses `HTMLVideoElement.currentTime` and the `timeupdate` event directly.

## Key Decisions

- **p-queue concurrency 1** on the pipeline queue — prevents SQLite BUSY errors from concurrent writes to the same asset row.
- **Groq 25 MB limit** — audio must be extracted to a 16kHz mono OGG temp file via ffmpeg before sending to the API. Delete the temp file in a `finally` block.
- **CORS** is only enabled in `NODE_ENV=development`.
- **OpenSearch failure is non-fatal** — search degrades gracefully; the app continues with SQLite-only operation.
- **`filepath` in SQLite is always relative to `STORAGE_ROOT`** — never store absolute paths.
- **Drizzle migrations** live in `backend/drizzle/`. Run `db:generate` after any schema change, then `db:migrate` to apply.
