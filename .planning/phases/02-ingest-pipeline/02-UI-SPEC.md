## Component Inventory

### 1. DropZone (`frontend/src/components/DropZone.tsx`)

**States:**

| State | Visual | Behavior |
|-------|--------|----------|
| Idle | Dashed border (`#2D2A5E`), centered icon + heading + subtext + button | Entire window is a drop target |
| Drag-over | Dashed border turns `#E11D48`, background tints `rgba(225,29,72,0.05)`, icon animates (scale pulse) | Visual feedback that a file can be dropped |
| Uploading | Drop zone fades out, replaced by ImportProgress | Transition: 200ms opacity fade |

**Layout:**
- Full viewport height and width (`min-h-screen`)
- Content vertically and horizontally centered (flexbox)
- Upload icon: Lucide `Upload` at 48px, color `#94A3B8`, transitions to `#E11D48` on drag-over
- Heading: "Drop a video file here" at 20px/600
- Subtext: "or" at 14px/400 in `#94A3B8`
- Button: "Choose File" primary CTA (see Copywriting Contract)
- Accepted formats hint below button: "MP4, MOV, MKV, AVI, WebM" at 12px/400 in `#94A3B8`
- Stack spacing: 16px between icon and heading, 8px between heading and subtext, 16px between subtext and button, 8px between button and formats hint

**Interaction:**
- Drag-and-drop activates on `window` (dragenter/dragover/drop events), not just the visible zone
- File input is hidden; "Choose File" button triggers it via ref
- Accepts `video/*` MIME type filter on the file input
- On file selection (drop or picker): immediately POST to `/api/assets`, transition to progress view on 202 response
- On duplicate error (409): show inline error (see Copywriting Contract), remain on drop zone

### 2. ImportProgress (`frontend/src/components/ImportProgress.tsx`)

**States:**

| State | Visual | Behavior |
|-------|--------|----------|
| Processing | Animated progress bar + stage label + elapsed timer | Polls GET /api/assets/:id every 2.5 seconds |
| Complete | Bar at 100%, green color, "Ready" label | Holds for 2 seconds, then resets to DropZone |
| Failed | Bar stops, red color, error message | Remains visible until user dismisses |

**Layout:**
- Centered container, max-width 480px, horizontally centered
- Stage label above bar: e.g. "Extracting metadata..." at 14px/500 in `#F8FAFC`
- Progress bar: full width of container, height 8px, rounded-full (4px radius)
- Progress bar track: `#1E1B4B` (panel)
- Progress bar fill: `#E11D48` (cta) during processing, `#10B981` (status-complete) on completion, `#E11D48` on failure
- Elapsed timer below bar: "0:34" at 14px/400 in `#94A3B8`, font-family Fira Code
- Error message (on failure): below the elapsed timer, 14px/400 in `#E11D48`
- Spacing: 8px between label and bar, 8px between bar and elapsed timer, 16px between timer and error message

**Progress bar animation:**
- The bar does NOT represent real percentage — stages have unknown duration
- Use an indeterminate animated shimmer (CSS animation: translate-x gradient sweep, 1.5s linear infinite) within the filled portion
- On stage transitions, the fill width steps forward in 4 increments: 25% (metadata), 50% (thumbnail), 75% (transcription), 100% (indexing complete)
- Transition between widths: 300ms ease-out

**Stage labels:**

| Stage | Label |
|-------|-------|
| metadata | "Extracting metadata..." |
| thumbnail | "Generating thumbnail..." |
| transcription | "Transcribing audio..." |
| indexing | "Indexing for search..." |
| complete | "Ready" |
| error (metadata/thumbnail) | "Import failed" |
| error (transcription soft-fail) | "Transcription failed — asset imported without transcript" |

**Elapsed timer:**
- Starts at "0:00" when ImportProgress mounts
- Increments every second via `setInterval` (local, not from server)
- Format: "M:SS" (no leading zero on minutes, always two digits on seconds)
- Stops on completion or failure

**Polling behavior (from CONTEXT.md):**
- Uses TanStack Query `refetchInterval` at 2500ms
- Stops when `status === 'ready'` or `status === 'error'`
- Maps server `*_status` fields to determine current stage and progress bar position

### 3. App Shell (`frontend/src/App.tsx`)

**State machine:**
- `idle` -> renders DropZone
- `uploading` -> file selected, POST in flight (brief, shows DropZone with disabled state)
- `processing` -> 202 received, renders ImportProgress with asset ID
- After ImportProgress completes -> returns to `idle` (renders DropZone)

## Interaction Contracts

### Drag-and-Drop

| Event | Response |
|-------|----------|
| `dragenter` on window | Drop zone border changes to `#E11D48`, background tints, heading changes to "Drop to import" |
| `dragleave` on window | Revert to idle state (200ms transition) |
| `drop` on window | Prevent default, extract file, begin upload |
| `dragover` on window | `e.preventDefault()` (required for drop to work) |

### File Validation (client-side)

| Check | Error copy |
|-------|-----------|
| No file in drop/picker | (silent — no action taken) |
| Non-video MIME type | "Please select a video file." |
| Multiple files in single drop | Accept all, queue sequentially (per IMP-01 multi-file support) |

### Multi-file behavior

When multiple files are dropped or selected:
- Each file uploads sequentially (one POST at a time)
- ImportProgress shows progress for the current file
- A small counter below the progress bar: "File 2 of 5" at 14px/400 in `#94A3B8`
- On completion of each file, automatically starts the next
- On failure of one file, show error briefly (3 seconds), then proceed to next file

## Transitions and Motion

| Transition | Duration | Easing | Property |
|------------|----------|--------|----------|
| Drop zone -> Progress view | 200ms | ease | opacity (fade out drop zone, fade in progress) |
| Progress bar width steps | 300ms | ease-out | width |
| Progress bar shimmer | 1.5s | linear | background-position (infinite loop) |
| Drag-over border/background | 200ms | ease | border-color, background-color |
| Success -> Reset to drop zone | 2000ms hold, then 200ms | ease | opacity |

All animations must respect `prefers-reduced-motion`:
- When active: disable shimmer animation, use instant transitions (0ms)
- Progress bar still shows width changes but without animation

## Accessibility

| Concern | Implementation |
|---------|---------------|
| Drop zone keyboard access | "Choose File" button is keyboard-focusable and activates file picker on Enter/Space |
| Focus ring | 3px `rgba(225,29,72,0.15)` box-shadow on focus-visible (matches MASTER.md input spec) |
| Screen reader: upload status | `aria-live="polite"` region wrapping ImportProgress stage label |
| Screen reader: progress | Progress bar uses `role="progressbar"` with `aria-valuenow` (25/50/75/100) and `aria-label="Import progress"` |
| Screen reader: drag-over | `aria-dropeffect="copy"` on the drop zone |
| Color contrast | `#F8FAFC` on `#0F0F23` = 18.06:1. `#94A3B8` on `#0F0F23` = 6.38:1. Both pass WCAG AA (4.5:1). |
| Status colors | Amber `#F59E0B` on `#0F0F23` = 9.74:1. Green `#10B981` on `#0F0F23` = 8.56:1. Both pass. |
